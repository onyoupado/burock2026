# 부락 2026 내 시간표

2026 부산국제록페스티벌(2026. 10. 2.~4., 삼락생태공원)에서 볼 무대를 골라 잠금화면 배경화면으로 저장하고, 링크 하나로 친구와 픽을 맞춰 보는 팬 메이드 웹페이지입니다.

## 기능

| 탭 | 하는 일 |
| --- | --- |
| 타임테이블 | 공식 타임테이블 5개 스테이지(SAMROCK·GREEN·RIVER·WAVE·HIDDEN) 99팀. 무대를 눌러 ★로 담고, 아티스트 인스타그램으로 이동 |
| 내 시간표 | 담은 무대를 시간순으로 정리. 쉬는 시간, 스테이지 이동, 겹치는 공연 표시 |
| 배경화면 | 무대 이름·시간·스테이지가 들어간 잠금화면 PNG 저장 (아이폰·Pro Max·갤럭시 규격, 테마 3종) |
| 먹거리·주류 | 푸드라운지·부산 로컬푸드·주류 부스 메뉴와 가격, 메뉴 검색 |
| 즐길거리 | HIDDEN 스테이지 액티비티 일정, 로부락존·삼락테마파크 등 부스, 부롱나이트 |
| 현장·굿즈 | 행사장 구역 요약, 공식·아티스트 MD, 셔틀, 물품보관소 |
| 친구 공유 | 내 픽이 담긴 링크 공유. 친구가 열면 타임테이블에 이름표로 표시 |

로그인과 서버가 없습니다. 내 픽과 메모는 각자 기기 브라우저(localStorage)에만 저장되고, 공유 링크의 `#` 뒤에 픽 정보가 들어갑니다.

## GitHub Pages로 올리기

1. GitHub에서 새 저장소를 만듭니다 (이름 `burock2026`). 공개(Public)로 만들어야 무료 Pages를 쓸 수 있어요.
2. `index.html`, `og.png`, `README.md`를 저장소에 올립니다 (Add file → Upload files).
3. 저장소 위쪽 메뉴 오른쪽 끝의 **⚙ Settings**를 누릅니다 (휴대폰이면 브라우저를 ‘데스크톱 사이트’로 보기).
4. 왼쪽 메뉴에서 **Pages**를 누릅니다.
5. **Build and deployment** 아래 **Source**가 `Deploy from a branch`인지 확인합니다.
6. 바로 아래 **Branch**의 첫 번째 칸 `None`을 눌러 `main`으로 바꿉니다. 옆 칸 `/(root)`는 그대로 둡니다.
7. **Save**를 누릅니다.
8. 1~2분 뒤 새로고침하면 Pages 화면 위쪽에 `Your site is live at https://onyoupado.github.io/burock2026/`가 뜹니다.

갱신할 때는 저장소에서 `index.html`만 새 파일로 덮어쓰면 됩니다. 방문자가 담아 둔 픽은 브라우저에 저장돼 있어 그대로 남습니다.

### 카카오톡 링크 미리보기 이미지

`index.html`의 `og:image`는 `https://onyoupado.github.io/burock2026/og.png`로 맞춰 두었습니다. 저장소 이름을 `burock2026`이 아닌 다른 이름으로 만들면 `index.html` 위쪽의 `og:url`·`og:image` 두 줄에서 `burock2026`을 바꿔 주세요.

## 데이터 출처와 수정

모든 정보는 2026. 10. 1. 기준 [공식 홈페이지](https://busanrockfestival.com) 타임테이블·라인업·공지와 공식 인스타그램 [@busanrockfest](https://www.instagram.com/busanrockfest/)에서 옮겼습니다. 현장에서 바뀔 수 있습니다.

- 타임테이블: `index.html` 안의 `const TT=` (형식: `이름|시작|끝|메모`)
- 인스타그램: `IG_O`(공식 최종 라인업 게시물·1차 라인업 공지에 태그된 80팀), `IG_S`(웹 검색으로 찾은 2차 라인업 등 19팀, 페이지에 점선으로 표시)
- 먹거리: `const FOOD=`, 즐길거리: `const FUN=`, `const BOOTHS=`

시간이 바뀌면 `TT`의 해당 줄만 고치면 됩니다. 단, 친구 공유 코드는 무대 순서로 만들어지므로 **무대를 추가·삭제하면 이전에 보낸 링크가 다른 무대를 가리킬 수 있습니다.** 시간만 고치는 건 괜찮아요.

## 안내

부산국제록페스티벌과 관련 없는 비공식 팬 메이드 페이지입니다. 공식 포스터·이미지는 사용하지 않았고, 상세 이미지는 공식 공지 링크로 연결합니다.
